# baseline-clock

把几个指数放到对数坐标上，用历次大底拟合一条**年化上行的基线**，再用「离基线多远」和「离基线还要多久」代替情绪，做买卖判断的一组自用脚本。

这里的"钟"不是预测顶底的钟，而是一把尺：基线按复利上移，价格横着不动，时间就会自己把空间补上。

## 核心概念

**基线**：取指数历次大底（阶段性低点）的对数价格做线性拟合，得到的底线。它的斜率就是这条指数长期底部抬升的速度，图上以年化百分比标注。

**三个读数**（每张图都标）：

| 读数 | 含义 |
| --- | --- |
| 较基线 | 现价 ÷ 基线 − 1，正数=在基线之上，负数=已跌破基线 |
| 历史分位 | 这个偏离在过去全部交易日中排第几百分位，越低越便宜 |
| 追平时间 | 假设价格完全不动，基线以年化速度上移，还要多久追上现价 |

**判断规则**：

- 追平时间 ≤ 1 年 → 落在可买区间
- 追平时间 > 1 年 → 持有或卖出，不新开仓
- 年化低的指数（比如沪深300 大约 5%），基线几乎是水平的，只能等价格真跌下来。所以这类指数的门槛设得更严：追平时间为 0（跌到基线）甚至更低才考虑。等待不花钱，空仓期间不会变贵。

## 快速开始

依赖 Python 3.9+ 和 matplotlib：

```bash
pip install matplotlib
```

每个脚本都无参数、无配置，直接跑：

```bash
python 成长100/growth100_triangles.py
python 价值100/value100_triangles.py
python 红利低波50/spc50_triangles.py
python 红利指数/spdiv_triangles.py
python 沪深300/deanchor.py
```

脚本按自身路径找数据和写图，在任何工作目录下运行结果都一样。CSV 缺失或过期会自动联网补齐，联网失败则退回本地数据继续画（终端会打印警告）。

典型输出：

```
saved 成长100_三角形周期与推演.png / .pdf
基线年化 13.31%｜当前 7422.10，较基线 +33.2%
推演底 2028-10-16 约 5938，基线届时 7153
```

## 数据来源与口径

**国证指数（价值100 / 成长100）**：国证指数官网日线，一次请求拿全历史。CSV 只存收盘价序列，图上再加**实时顺延**——日线还没更新到当天时，用东财实时点位补一个当日点（成长100：`secid=0.980080`）。

**标普两个指数**：标普没有公开日线接口，所以用跟踪同一指数的境内基金做全收益代理，序列从基金成立日起、×1000 画图（成立日 = 1000）。与因管理费及其他原因，会与对应的指数偏低。

- 红利低波50 → 南方标普中国A股大盘红利低波50ETF（515450）的**净值 + 分红再投资**，从 2020-01-17 起
- 红利机会 → 华宝标普中国A股红利机会指数A（501029）的**累计净值**（≈ 单位净值 + 累计分红），从 2017-01-19 起

**沪深300（债锚）**：中证指数官网单次全量抓取 H00300（沪深300全收益）与 H11023（中证债券型基金指数），起点 2005-01-04 = 1000。k=1.4437 由 13 个历史阶段性底部（2008-11 ~ 2025-04）的对数最小二乘得出，输出今日锚位和"还需要跌多少"。

## 盘中顺延（fill_live）

当日净值收盘后才出，所以盘中想看当日点位，就用跟踪基金/指数本身的最新报价把序列顺延到当天。真实数据出来后会被覆盖。

| 脚本 | 实时来源 | 说明 |
| --- | --- | --- |
| 成长100 | 东财指数实时点位 | 日线落后 1 天时补当日点；落后多天（比如长假）则跳过，先等日线 |
| 红利低波50 | 腾讯 `sh515450` 前复权成交价 | 净值未更新时按成交价比值顺延，图上当日点画橙色虚线 |
| 红利机会 | 腾讯 `sh562060` 成交价（主）、`sh501029`（兜底） | 562060 单价约 0.62 元、一跳 0.001 元 ≈ 0.16%，顺延点有 ~0.1% 量级报价噪声 |
| 价值100 | 无 | 国证官网夜间更新日线，盘中不出点 |
| 沪深300 | 无 | 中证官网单次全量，按最近交易日计算 |

## 输出物

- `*_triangles.py`：同目录的 `*.png` / `*.pdf`，加终端一行结论（基线年化｜当前值｜较基线｜历史分位｜追平时间）
- `deanchor.py`：`hist_csi.csv`（全量缓存）、`csi_2026_daily_*.csv`（逐年）、`an_anchor_today.csv`（今日锚位快照）、`deanchor_today.png`（对数坐标主图），终端打印锚位与还需跌幅；`--no-chart` 只出数据

## 已知限制

- 基线是事后拟合：新增一个更低的低点，斜率、年化、历史分位都会跟着变，读数会小幅漂移。
- 标普两个指数用跟踪基金代理，与官方全收益指数接近但不完全相等；基金成立前的历史没有。
- 盘中顺延用成交价换算，ETF 折溢价和报价噪声会带进点位。
- 三角形转折点是人工标定的，最新一轮的底常常还是"未确认"状态。
